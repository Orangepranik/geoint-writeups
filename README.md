# GEOINT writeups

Решённые задачи по геолокации изображений (GEOINT / OSINT): по одному кадру
определить, где и когда он снят. В каждой папке — исходное задание, ход
решения со скриншотами и ответ.

## На что стоит обратить внимание

Если времени мало, начните с этих разборов — в них лучше всего виден метод:

- **[Одесса, 20.07.2026](odesa-2026-07-20/)** — реальный кейс: место съёмки
  по вертикальному видео без геометки. Overpass-запрос по отделениям полиции
  для сужения района, план застройки, срисованный с видео, сверка с панорамами
  2011/2015 годов с учётом новостроек, парные люки тепловой камеры как
  ориентир во дворе. Отдельно — оценка роста человека по пикселям с поправкой
  на перспективу.
- **[GEOINT 1](geoint-01/)** — много мелких зацепок сводятся в одну точку:
  региональные газеты в киоске («Череповецкая истина»), баннер застройщика
  с улицей и телефоном, регионы на номерах машин, план зданий, срисованный
  с кадра. Поиск по OSM, Google Maps и F4map.
- **[GEOINT 2](geoint-02/)** — работа с текстовыми подсказками в условии
  (Лох-Несс, Озёрный край): сужение до региона, затем моделирование
  береговой линии и перебор 16 озёр.
- **[GEOINT 3](geoint-03/)** — дорожные знаки и столбы через GeoHints
  сужают страну, атмосферное давление указывает на высоту над уровнем моря,
  а здание восстанавливается ИИ-генерацией для обратного поиска.
- **[GEOINT 8](geoint-08/)** — человек в кадре мешает обратному поиску:
  его вырезают из кадра и ищут уже по интерьеру. Этаж оценивается по виду
  из окна.
- **[GEOINT 12](geoint-12/)** — метаданные фото оказались ложными. Сеть
  отелей сужается Overpass-запросом по Малайзии, нужный отель находится
  сравнением архитектуры.
- **[GEOINT 244](geoint-244/)** — решена частично, но хорошо видно, как
  сужать поиск без текста и вывесок: оливковые деревья, сухая каменная
  кладка, рельеф. Получилась таблица из пяти стран, высота гор
  оценивалась по масштабу деревьев и кладки.
