Методология определения роста:
1. Определяем размеры изображение, его качество, расширение, для этого используем утилиту.
2. Смотрим ближайшие ориентиры, и используем математические формулы, каждый пиксель имеет свое заданное растояние, которое можно рассчитать.
3. Подставляем и получаем исходные данные, из большого фрагмента можно рассчитать точность до сантиметра, но в данном кейсе нам это не понадобиться, и мы примерно выведем данные.


## 1. Выбираем эталон
Берём длину обуви мужчины:
- длина обуви в кадре: `P₁ ≈ 95 px`;
- предполагаемая реальная длина обуви: `L₁ ≈ 28 см`.
Масштаб возле мужчины:
```
S₁ = L₁ / P₁
S₁ = 28 / 95
S₁ ≈ 0,295 см/пиксель
```
## 2. Простая формула без перспективы
Если бы лавка находилась на том же расстоянии:
```
Lлавки = Pлавки × S₁
```
Например:
```
Lлавки = 180 × 0,295
Lлавки ≈ 53 см
```
Это очевидно слишком мало. Причина — лавка находится дальше и занимает меньше пикселей на каждый сантиметр.
## 3. Исправляем перспективу
Нужно определить:
- `Y₀` — горизонт/точка схода перспективы;
- `Y₁` — положение стопы человека на земле;
- `Y₂` — положение нижней точки лавки на земле.
Приблизительно по этому кадру:
```
Y₀ ≈ 380 px
Y₁ ≈ 745 px
Y₂ ≈ 575 px
```
Коэффициент перспективы:

```
K = (Y₁ − Y₀) / (Y₂ − Y₀)
```
Подставляем:

```
K = (745 − 380) / (575 − 380)
K = 365 / 195
K ≈ 1,87
```
То есть лавка находится примерно в `1,87 раза` дальше от камеры, чем нога мужчины.
## 4. Рассчитываем длину видимой части лавки
Видимая длина лавки примерно:
```
Pлавки ≈ 180 px
```
Формула:
```
Lлавки = (Pлавки / P₁) × L₁ × K
```
Расчёт:
```
Lлавки = (180 / 95) × 28 × 1,87
Lлавки ≈ 99 см
```
Это длина только видимой проекции. Часть лавки перекрыта ограждением, а сама лавка может быть расположена под углом.
С учётом перекрытия:
```
Lполная = Lвидимая / (1 − F)
```
где `F` — доля скрытой части.
Если скрыто 15–25%:
```
Lполная = 99 / 0,85 ≈ 116 см
Lполная = 99 / 0,75 ≈ 132 см
```
С учётом угла расположения лавки получаем ориентировочно:
```
Длина лавки ≈ 1,2–1,5 м
```
Наиболее вероятное значение — около **1,3–1,4 м**.
## 5. Формула для высоты лавки
Для вертикальных размеров используется формула:

```
Hлавки =
Hэталона × (Pлавки / Pэталона) × K
```

Если взять рост мужчины примерно `178 см`, его высоту в кадре `600 px`, а высоту сиденья лавки в кадре примерно `80 px`:

```
Hсиденья =
178 × (80 / 600) × 1,87
Hсиденья ≈ 44 см
```

Это соответствует обычной высоте паркових лавок.
Для общей высоты лавки, если от земли до верхней части спинки примерно `155 px`:
```
Hобщая =
178 × (155 / 600) × 1,87
Hобщая ≈ 86 см
```
